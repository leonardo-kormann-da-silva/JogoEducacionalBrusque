# JogoEducacionalBrusque
Este jogo educativo foi desenvolvido para ensinar, de forma divertida e interativa, os principais lugares e elementos presentes em uma cidade. O jogador responde perguntas sobre locais como escola, hospital, museu e praça, acumulando pontos a cada acerto. Ao final, recebe uma mensagem de desempenho de acordo com sua pontuação. O objetivo é estimular o aprendizado sobre o espaço urbano e a importância de cada lugar no cotidiano das pessoas.
